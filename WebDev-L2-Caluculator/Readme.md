🧮 Calculator - OASIS INFOBYTE Web Development L2
📌 Project Overview
A fully functional browser-based calculator built with vanilla HTML, CSS, and JavaScript. This project demonstrates core web development skills including DOM manipulation, event handling, mathematical logic, and responsive design.
Live Demo: Open index.html in any modern web browser.
🎯 Features Implemented
✅ Core Functionality
Display Screen: Shows current input and calculation results in real-time
Number Buttons (0-9): Input numeric values
Decimal Point: Support for floating-point numbers
Operator Buttons: Addition (+), Subtraction (−), Multiplication (×), Division (÷)
Equals Button: Evaluate expressions and return results
Clear Button (C): Reset calculator to initial state
Backspace/Delete Button: Remove last entered character
Division by Zero Handling: Prevents crashes with user-friendly error message
⚡ Advanced Features
Operator Chaining: Perform sequential operations (e.g., 5 + 3 × 2) without manual reset
CSS Grid Layout: Responsive button layout using modern CSS Grid
No Event Listeners on HTML: All event handling done via JavaScript (best practice)
Keyboard Support:
Number keys (0-9) for input
+ - * / for operators
Enter or = for equals
Escape for clear
Backspace for delete
Floating-Point Precision: Rounds results to avoid JS floating-point errors (e.g., 0.1 + 0.2)
Responsive Design: Works seamlessly on desktop, tablet, and mobile devices
Accessibility: Proper ARIA labels and keyboard focus states
